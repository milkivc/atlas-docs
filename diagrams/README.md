# Mermaid Diagrams

This directory contains Mermaid diagrams for the Atlas Vivo ecosystem.

## Version History

All diagrams are versioned through Git commits. Each update to a diagram results in a new commit with a descriptive message.

## Current Diagrams

- **atlas-vivo-architecture.mmd**: System architecture diagram showing the relationships between Atlas Vivo components, Codeberg, Zenodo, ORCID, and Portuguese metadata systems (SNIG/AMA).

## Update Process

1. Edit diagrams locally in the skills directory
2. Run the update script to extract and push changes
3. Commit messages follow the format: "Update [diagram-name]: [description of changes]"
