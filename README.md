# Atlas Docs — Documentação Fundacional da Associação MILK

Documentação jurídica, institucional, metodológica e de governação da Associação MILK — Movimento de Intervenções e Linguagens Kulturais e Arte.

## Regra de publicação

Este repositório contém somente documentação autorizada para divulgação. Informações pessoais, credenciais, negociações, dados comunitários sensíveis e documentação ainda em revisão permanecem em camadas privadas.
